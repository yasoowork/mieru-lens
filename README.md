# MieruLens

MieruLensは、スマートフォンのカメラ映像をリアルタイムで補正し、輪郭や色の見やすさを補助するWebアプリです。

## URL

https://mierulens.yasoo.work

## 概要

- カメラ映像をリアルタイムに補正
- くっきりモード（輪郭・コントラスト強調）
- 色補助モード
- C / P / D / T / A タイプ切替
- 端末内処理（サーバー送信なし）
- 写真保存なし

## 使い方

1. カメラの利用を許可
2. モードを選択（くっきり / 色）
3. スライダーで強さを調整

## 注意

本アプリは視認補助を目的としたツールです。  
医療用途・診断・安全確認を代替するものではありません。

## プライバシー

カメラ映像は端末内で処理され、サーバーへ送信されることはありません。

```bash
